# fhdl

FORTH to verilog generator

Приложение на gforth для создания verilog файлов проектов на выходе на базе файлов определений forth. Разработана специальная разметка для файлов на gforth. Приложение парсит эти файлы, собирает данные в структуры памяти и создает итоговый модуль на verilog. Полностью модули verilog вместе со всеми логическими функциями языка Verilog генерировать пока цели не ставилось. Для начала генерировать только главный модуль, а остальные модули только подключать - инстанцировать. И соединять их между собой в главном модуле.

```
alias fhdl='gforth ~/fhdl/fhdl.4th -e'
```

Код сначала писался самостоятельно, но теперь пробую через Gemini3

## Test conversion

```
fhdl build project3.4th 
```

Input file

```
\ project3.4th
module: flexible_adder
    \ Параметры
    parameter: WIDTH = 8;
    parameter: INIT_VAL = 0

    \ Используем параметры в шинах (в парсере пока нет eval параметра, 
    \ поэтому ширину указываем числом, но для Verilog это валидно,
    \ если мы добавим поддержку параметра как ширины в будущем.
    \ Пока ширину шины пишем явно числом, так как `input-bus:` делает `evaluate`)
    
    input-bus: a 8
    input-bus: b 8
    output-bus: sum 8
    
    assign: sum = a + b + INIT_VAL;
end-module

```

Output
```
[BUILDER] Parsing file: project3.4th

// Generated by FHDL
module flexible_adder (a, b, sum);
  parameter WIDTH = 8;
  parameter INIT_VAL = 0;
  input [7:0] a;
  input [7:0] b;
  output [7:0] sum;

  assign sum = a + b + INIT_VAL;
endmodule
```
