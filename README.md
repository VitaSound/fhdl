# FHDL (Forth HDL)

**FHDL** is a Gforth-based application for generating Verilog project files from Forth definitions. It introduces a specialized markup (DSL) within Forth files, which the application parses to build memory structures and generate a final Verilog module.

Currently, the tool focuses on generating the **top-level module**—defining interfaces, parameters, and instantiating/connecting sub-modules—rather than generating complex behavioral logic (though basic assignments are supported).

## Features

*   **Forth-based DSL:** Write hardware definitions using Forth syntax.
*   **Verilog Generation:** Automatic generation of `module`, `endmodule`, ports, and parameters.
*   **Parameter Support:** Handles Verilog `parameter` definitions with flexible syntax (with or without `=`, `;`).
*   **Bus & Port Management:** easy definition of `input`, `output`, and `inout` ports (single bit or bus).
*   **Attributes:** Support for `reg` and `signed` attributes on ports.
*   **Logic Assignments:** Support for continuous `assign` statements.
*   **CLI Interface:** Simple command-line tools (`build`, `version`, `help`).

## Installation

### Prerequisites

1.  **Gforth**: Ensure Gforth is installed on your system.
2.  **fmix**: This project uses [fmix](https://github.com/phreda4/fmix) for package management.

### Setup

1.  Clone the repository.
2.  Install dependencies using `fmix`:
    ```bash
    fmix packages.get
    ```
3.  Create an alias for easier usage. Add the following to your shell configuration (`.bashrc`, `.zshrc`, etc.):
    ```bash
    alias fhdl='gforth ~/path/to/fhdl/fhdl.4th -e'
    ```

## Usage

### Commands

*   **Build a project:**
    ```bash
    fhdl build <filename.4th>
    ```
    *Note: The Verilog code is currently output to `stdout`. To save it to a file, use redirection:*
    ```bash
    fhdl build project.4th > project.v
    ```

*   **Check version:**
    ```bash
    fhdl version
    ```

*   **Help:**
    ```bash
    fhdl help
    ```

## Syntax Guide

FHDL uses a specific set of words to define hardware.

### Module Definition
```forth
module: my_module_name
    \ ... definitions ...
end-module
```

## Parameters

Parameters can be defined in standard Verilog style or Forth style.

```
parameter: WIDTH = 8;
parameter: INIT_VAL = 0
parameter: DEPTH 32       \ Forth style (no equals)
```

## Ports

 * Single bits: input: name, output: name, inout: name
 * Buses: input-bus: name width, output-bus: name width
 * Attributes: Use reg or signed before the port definition.

```
input: clk
input: rst
input-bus: data_in 8

reg output: valid_flag
signed output-bus: result 16
```

## Assignments

Basic combinational logic.

```
assign: sum = a + b + INIT_VAL;
assign: inverse_out = ~data_in;
```

# Example

Input File (project3.4th):

```
module: flexible_adder
    \ Parameters
    parameter: WIDTH = 8;
    parameter: INIT_VAL = 0

    \ Bus definitions
    \ Note: Widths currently require numeric literals.
    input-bus: a 8
    input-bus: b 8
    output-bus: sum 8
    
    \ Logic
    assign: sum = a + b + INIT_VAL;
end-module
```

Generated Output:

```
// Generated by FHDL
module flexible_adder (a, b, sum);
  parameter WIDTH = 8;
  parameter INIT_VAL = 0;
  input [7:0] a;
  input [7:0] b;
  output [7:0] sum;

  assign sum = a + b + INIT_VAL;
endmodule
```

# Project Structure

 * fhdl.4th: Main entry point and CLI argument parser.
 * fhdl.builder.4th: Core logic for parsing the DSL and generating Verilog strings.
 * reader.fs: Configuration reader (parses package.4th).
 * tests/: Contains unit tests (e.g., builder_test.4th) using ttester.

#  Running Tests
